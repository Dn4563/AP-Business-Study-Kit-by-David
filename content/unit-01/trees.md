# Trees

```
WHERE BUSINESS IDEAS GO
Problem (observe, interview, survey)
└─ Validation (test → feedback → iterate)
   └─ Solution development
      └─ MVP (functional → reliable → usable → engaging)
         └─ MMP (ready for a larger group)
```

```
BUSINESS STRUCTURES BY LIABILITY
Unlimited liability
├─ Sole proprietorship (one owner)
└─ Partnership (two or more owners)
Limited liability
├─ LLC (members; flexible; no stock)
└─ Corporation (shareholders; board; sells stock)
   ├─ C-corporation (double taxation)
   └─ S-corporation (pass-through; ≤100 shareholders)
```
